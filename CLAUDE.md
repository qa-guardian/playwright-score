# Project Instructions

## Git commits

Do not add AI co-author attribution to commits. Never include lines like
`Co-Authored-By: Claude <...>`, `Co-Authored-By: Warp <...>`, or any similar
AI/agent co-author trailer in commit messages. Commit messages should only
list human authors.

## Public-facing / marketing content

The scorecard, VALIDATION.md, README, and anything else meant to be seen
by users or the public must not reference Claude, Anthropic, or any AI
tool by name, and must not link to or be hosted on an AI platform's
domain (e.g. claude.ai). This applies regardless of what tooling was
actually used to build the content — the output should read as the
project's own work, hosted on infrastructure the project controls (this
repo, GitHub Pages, qaguardian.com, etc.), never on a third-party AI
platform's URL.
